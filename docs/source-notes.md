# Project context

## Course brief

This project follows the CS 6180 Microstrip Field Diffusion brief by Jiaji Huang. The brief defines the prediction task, fixed data splits, baseline, and evaluation criteria for a three-person team.

- [Original brief](../reference/project-proposal.pdf)
- [Searchable text](../reference/project-proposal.txt)
- [Experiment plan](project-plan.md)

## Shared references

The [reference folder](../reference/README.md) collects the seven background readings recommended in the brief, following Ivan Biggs's suggestion to keep the literature together for the team. The reading guide connects each paper to the relevant model or experiment.

## Scope

The core comparison is DeepONet regression versus direct conditional diffusion. Fourier features and residual diffusion are planned extensions. Architecture choices and evaluation details are documented in the experiment plan; results will be added after the baseline and model runs.
