Background
A microstrip is a copper trace on an insulating board (the substrate), with a copper ground plane
underneath. Its geometry is described by the substrate thickness h , the trace width w and thickness t ,
and the substrate's permittivity ε_r . For 9,789 designs, a solver computed the electric field in the cross-
section as a two-channel image. The field is smooth in most of the image and very sharp at the trace's
corners, which makes it a good test of regression versus diffusion.

The task
  Input                                  x ∈ ℝ⁴


  Predict                               the image u ∈ ℝ2×64×128

  Loss                                  over unmasked pixels only

  Evaluate                              on u , over unmasked pixels

u is each design's field divided by its own peak value, so every image lies in [−1, 1]. The peak varies 25×
across designs; predicting it is not part of the task, which is about the shape of the field.

Each design has exactly one correct field, so this is regression. Networks trained with mean squared
error tend to blur sharp features; diffusion models are known to keep fine detail. Whether that holds
here, and at what cost, is the question. A carefully measured negative result is a good result.

  Branch                     MLP on x → b ∈ ℝ2×p: one set of p coefficients per channel of u
                             (for example p = 64)

  Trunk                      MLP on a pixel's coordinates ( y_over_h , z_over_h ) → τ ∈ ℝ2×p:
                             one set of p basis values per channel. In the original DeepONet (Lu
                             et al.) the trunk is a plain MLP on the raw coordinates. Plain MLPs
                             on coordinates tend to blur sharp features, so a common addition,
                             not part of the original design, is to feed Fourier features instead
                             (Tancik et al.): sin and cos of 2π · B · ( y_over_h , z_over_h ), with B a
                             fixed random 128 × 2 matrix. Start with the plain trunk, then add
                             Fourier features and report the difference at the trace edges.

  Output                     u[c] at that pixel = b[c] · τ[c] , the dot product of the two length-

                             p vectors, for c = 0, 1. Allowed alternative: a shared trunk, τ ∈ ℝp,
                             with u[c] = b[c] · τ , so both channels use the same basis.

MODEL 2 · DIFFUSION

Conditional diffusion (DDPM)

  Generated                  u (2 channels). Only u is noised and denoised.


  Denoiser                   small U-Net on 64 × 128 images (5–20 M parameters). Output: its
                             estimate of the noise in u , 2 channels.

  Condition                  x , through a small MLP embedding added to the timestep
                             embedding

  Training                   predict the added noise, MSE over unmasked pixels; about 1,000
                             noise steps

  Sampling                   DDIM, 20–50 steps; after every step, set the masked pixels of u back
                             to 0

This is a standard conditional DDPM: the same setup as class-conditional image generation, with x in
place of the class label. That works here because the pixel grid is already normalized per design:

  • z_over_h is identical for every design: the rows always sit at the same heights in units of h .
  • y_over_h depends only on w/h: the columns always span ±(w/h / 2 + 6).
  • The mask always lies in rows 31–33; only its width and thickness vary, with w/h and t.




                                                                                                      Page 5 of 7
So the coordinates and the mask carry no information beyond x , and the network can learn the
geometry from x alone. Giving it the geometry explicitly may still help it place the sharp edge lobes.
Ways to try, as ablations:

  • Coordinate channels: add y_over_h (repeated down every row) and z_over_h (repeated across
   every column) as two extra input channels, the same at every step; or their Fourier features.
  • Mask channel: add mask as a 0/1 input channel, or a map of each pixel's distance to the trace.
  • Grid-free denoiser: treat pixels as points with coordinates, for example a transformer over pixel
   tokens.

Start with the diffusion model generating u directly. Then try the residual version: it generates only
the correction u − u_DeepONet , with the DeepONet prediction as an extra input channel. Regression
gets the smooth bulk right and diffusion adds the detail; this usually trains faster.


How to compare
  • Splits: tune on val , report on test . Report test_extrap separately: it holds the thickest 10% of
   substrates (h ≥ 0.722 mm), never seen in training.
  • Baseline: PCA on the training images (32 components) plus a Gaussian process from x to the
   coefficients. A model that does not beat it is not worth reporting. A ready-to-run script is at
    /courses/CS6180.202710/shared/final_proj/pca_gp.py ; it needs numpy, scipy, h5py and scikit-
   learn, and takes about 25 minutes on 8 CPUs.
  • Fairness: same data and inputs for every model; state each model's parameters and GPU-hours.
